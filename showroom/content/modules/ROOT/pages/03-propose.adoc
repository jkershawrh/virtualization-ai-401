= 3. PROPOSE

== Show

A proposal names exactly one VM and one operation: `LIVE_MIGRATE`,
`VALIDATE_RECOVERY`, or `RESTORE_REVIEW`.

== Learn

The approval digest binds the reviewer to the exact request. Wildcards and
fleet actions are outside this level.

== Do

[source,bash,role="execute"]
----
curl -fsS "$PRESENTATION_URL/fixtures/approved-migration-request.json" -o /tmp/op-request.json
jq '{request_id,operation,target,approved_by:.approval.approved_by}' /tmp/op-request.json
----

== Prove

[source,bash,role="execute"]
----
jq -e '.target.virtual_machine != "" and (.approval.operation_digest | startswith("sha256:"))' /tmp/op-request.json
----
