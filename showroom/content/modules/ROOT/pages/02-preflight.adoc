= 2. PREFLIGHT

== Show

The deterministic gate checks identity, network, storage, freshness, and
correlation before any proposal advances.

== Learn

A known incompatibility returns `REFUSE`. Stale or incomplete evidence returns
`ABSTAIN`. Complete preflight returns `ALLOW_REVIEW`, not permission to act.

== Do

[source,bash,role="execute"]
----
curl -fsS "$SHOWROOM_URL/fixtures/healthy-migration.json" -o /tmp/op-healthy.json
jq '{request_id,operation,source_state,decision,reason_codes}' /tmp/op-healthy.json
----

== Prove

[source,bash,role="execute"]
----
jq -e '.source_state == "REHEARSAL" and .authority.automated_action_performed == false' /tmp/op-healthy.json
----

The presentation fixture is evidence of the contract, not a current operation.
