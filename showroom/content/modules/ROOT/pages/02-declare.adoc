= 2. Declare control intent

Inspect `contracts/governance-policy.json` and
`contracts/modernization-request.schema.json`. Declare the expected namespace,
VM, caller service account, Service and port, architecture, and required labels.

Keep credentials out of the request. A live model credential belongs only in a
runtime Secret referenced by the adapter Deployment. The VM, presentation,
fixtures, evidence, and source must contain no credential value.

Explain the order: identity → network → observability → placement → model.
Identity and network mismatches `REFUSE`; missing observations `ABSTAIN`.
