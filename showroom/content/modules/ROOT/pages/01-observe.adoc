= 1. OBSERVE

== Show

Open the OpenShift Console *VirtualMachines* view for this project. Observe the
`operations-client` VM separately from the operations adapter Deployment, then
open *Storage → PersistentVolumeClaims* to see the evidence ledger claim.

== Learn

VM identity, storage, service health, and AI dependency health are different
facts. Never infer model, provider, Intel placement, CPU allocation, or
utilization from a Running pod.

== Do

[source,bash,role="execute"]
----
oc get virtualmachines,virtualmachineinstances -n "$LAB_NAMESPACE" -o wide
----

[source,bash,role="execute"]
----
oc get deployment,service,persistentvolumeclaims -n "$LAB_NAMESPACE" \
  -l app.kubernetes.io/instance=virtualization-ai-401
----

== Prove

Record which facts are directly observed. Factory fixtures remain
`REHEARSAL`; unknown facts remain unknown.
