= 3. Collect observations

Collect observations independently from the submitted declaration: launcher
pod service account, VM/VMI identity and UID, Service and ready endpoints,
NetworkPolicy, VMI node, node architecture and required labels, events, and one
correlation identifier. Redact unrelated metadata.

The reference chart uses the pod network with masquerade, a namespace-local
Service, default-deny adapter policy, and a labeled launcher exception. It does
not create a secondary network or cluster-scoped object.

`/metrics` exposes only in-process decision counts. Do not interpret those
counters as VM, cluster, model, capacity, efficiency, or response-time proof.
