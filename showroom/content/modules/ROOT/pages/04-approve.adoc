= 4. APPROVE

== Show

Only a named, time-bounded human approval can move the evidence journey beyond
proposal. `HUMAN_APPROVAL_REQUIRED` remains the authority boundary. The adapter
and optional language model have no approval authority.

== Learn

Digest mismatch or expiry must `REFUSE`. The final interpretation and any real
target action remain human-owned.

== Do

[source,bash,role="execute"]
----
jq '{approved_by:.approval.approved_by,expires_at:.approval.expires_at,digest:.approval.operation_digest}' /tmp/op-request.json
----

== Prove

[source,bash,role="execute"]
----
test "$(jq -r '.authority.human_review_required' /tmp/op-healthy.json)" = true
----
