= 5. Exercise refusal and abstention

Run each condition through the same endpoint and preserve the returned record:

|===
|Condition |Expected outcome |Model use
|Observed VM or service account differs |`REFUSE / IDENTITY_MISMATCH` |Not run
|Service, port, policy, or endpoints differ |`REFUSE / NETWORK_MISMATCH` |Not run
|Correlation or events missing |`ABSTAIN / OBSERVABILITY_INCOMPLETE` |Not run
|Node, architecture, or labels absent |`ABSTAIN / PLACEMENT_UNKNOWN` |Not run
|Observed placement contradicts policy |`REFUSE / PLACEMENT_MISMATCH` |Not run
|Approved model unavailable after controls pass |`ABSTAIN / MODEL_UNAVAILABLE` |Failed closed
|===

No refused or abstained response may contain advisory output or claim model
participation. Check that identity failure stops later checks (`NOT_RUN`).
