= 4. Compare and allow review

Run the contract and workload tests, render the chart, then submit the complete
representative request. In factory mode the expected result is:

* outcome `ALLOW_REVIEW`;
* source state `REHEARSAL`;
* `ai_participated: false`;
* reason `CONTROLS_COMPLETE`; and
* authority `HUMAN_REVIEW_REQUIRED`.

Retrieve the evidence by its identifier and verify the request hash,
correlation identifier, ordered checks, source state, timestamp, and authority.
`ALLOW_REVIEW` permits review only; it does not authorize a change.
